# Gauntlet ledger — Power BI 量本利分析 圖解導覽影片

## 製作方式（與電商版、醫療版、庫存版同一條管線）
- 畫面：線上公開發佈版報告（Publish to web）以 puppeteer 逐頁 2.5× 截圖 → `assets/p{i}_film.jpg`（3000 px 寬，影片用）、`_hi`（2400，網頁放大用）、`p{i}.jpg`、`_s`。
  - 為什麼不用 Desktop Bridge：頁面是 1200×1500 直式，只截得到上半頁，且原生圖表頁在 Desktop 截圖中是空白。
- 數字：影片與互動頁的數字取自畫面讀值，並用 Power BI Modeling MCP 對本機模型查詢、CSV 加總驗算（營收、固定費用、列數、關聯數、度量值數）。
- 旁白：Gemini TTS（Kore）逐場景生成 → 修頭尾靜音（vo/）→ 重取樣 44.1k（vo44/）→ `build_timeline.py` 依旁白長度排時間軸。
- 畫面渲染：`stage.html` 的 `render(t)` 是時間的純函式；`render.js` 以 puppeteer 逐格截圖 → ffmpeg。
- 配樂／音效：`mkaudio.py` 程式合成柔和鋼琴＋pad（72 BPM）與轉場音效；loudnorm −16 LUFS，TP −2。另附純配樂備援軌 `music_only.wav`。
